1. Product Overview 
TrustLens is an AI-powered trust scoring engine that analyses any digital platform across five 
independent signals and produces a single, explainable Trust Score (0–100). Think of it as a 
credit score for data privacy — except it works for platforms, not people. 
 
The Problem 
Users interact with hundreds of digital platforms daily with zero visibility into how responsibly 
those platforms handle their personal data. Existing tools are either too technical, outdated, or 
rely on self-reported compliance claims. India’s DPDP Act 2023 and GDPR have created 
regulatory accountability structures, but users still lack a real-time, accessible trust signal at the 
point of interaction. 
 
The Solution 
TrustLens gives users a single, independently generated, plain-English score for any platform 
— powered by five automated signals: privacy policy analysis, breach history, regulatory 
compliance, user complaint patterns, and third-party tracker detection.

3. Complete Feature List 
3.1 Trust Score Engine (Core) 
• Composite score 0–100 across 5 weighted signals 
• Grade system: A (80–100) / B (60–79) / C (40–59) / D (20–39) / F (0–19) 
• Colour-coded grade badge: Green / Blue / Yellow / Orange / Red 
• "Last Updated" timestamp on every score card 
• Score trend indicator — 📈 improved / 📈 declining (based on historical delta) 
• Scores cached in PostgreSQL for instant repeat lookups 
 
3.2 Signal 1 — Privacy Policy Analysis (20 pts) 
• Auto-fetch and scan the platform’s privacy policy via URL scraping 
• Red-flag clause detection (e.g. "we may share with partners", "we retain data 
indefinitely") 
• Positive signal detection (e.g. explicit data minimisation, clear deletion policy) 
• Plain-English summary of the 3 biggest risks found 
• Powered by Gemini API (free tier, 1500 req/day) 
• Sub-score displayed with reason for each deduction 
 
3.3 Signal 2 — Data Breach History (30 pts) 
• Check if platform domain has been in any recorded breach (HIBP free /breaches 
endpoint) 
• Show breach date, number of users affected, and data types exposed 
• Severity scoring: HIGH / MEDIUM / LOW based on recency and scale 
• Visual breach detail card: 
◦ Platform name, breach date, user count affected 
◦ Data exposed: Emails, Passwords, Phone numbers, etc. 
◦ Severity label with point penalty shown 
• Historical breach timeline if multiple breaches exist

3.4 Signal 3 — Regulatory Compliance (20 pts) 
• Structured compliance checklist against India’s DPDP Act 2023 
• GDPR alignment check for platforms serving EU users 
• Checklist items evaluated: 
◦ Clear consent mechanism present 
◦ Data deletion / erasure request process exists 
◦ Data Protection Officer (DPO) mentioned 
◦ Data retention period clearly stated 
◦ Third-party sharing disclosed with opt-out 
• Prominent DPDP Compliance Badge: ✅ Compliant / ❌ Non-Compliant 
• Unique India-specific differentiator — no other tool does this 
 
3.5 Signal 4 — User Complaint Analysis (15 pts) 
• Aggregate privacy-related complaints from app store reviews and consumer forums 
• HuggingFace Inference API for sentiment + topic classification 
• Classify complaints by category: data misuse, spam, unauthorised sharing, tracking 
• Show complaint volume and top complaint themes 
• High complaint volume on privacy topics = score penalty 
 
3.6 Signal 5 — Third-Party Tracker Detection (15 pts) 
• Detect trackers using Exodus Privacy open dataset (downloadable CSV) 
• Cross-reference Mozilla Privacy Not Included listings 
• Show exact tracker names and their parent companies 
• Plain-English output: "Instagram has 12 trackers sending your data to Facebook, 
Google, and 3 data brokers" 
• More trackers + data broker partnerships = higher penalty

• Colour-coded per-signal breakdown with sub-score and max score 
• Progress bar for each signal (visual score representation) 
• Expandable detail cards per signal (click to see full reasoning) 
• Overall grade badge prominently displayed at top

6. System Architecture 
6.1 Request Flow 
1.  User types platform name in React frontend 
2.  React sends GET /score?platform=zomato to FastAPI backend 
3.  FastAPI checks PostgreSQL — is there a cached score? 
       YES → return instantly 
       NO  → trigger all 5 signal modules in parallel 
4.  Each module returns a sub-score (0–30 depending on weight) 
5.  scikit-learn scoring engine combines them into final score 
6.  Result stored in PostgreSQL for future cache hits 
7.  JSON response returned to React 
8.  React renders: score, grade, breakdown, trend graph, action steps 
 
6.2 Backend Module Breakdown 
Module Responsibility 
policy_analyzer.py Fetch privacy policy URL, send to Gemini API, parse red flags, return 
sub-score 
breach_checker.py Call HIBP /breaches, filter by domain, score severity + recency 
compliance_checker.py Run DPDP/GDPR checklist, return sub-score and badge status 
complaint_analyzer.py Call HuggingFace sentiment API on scraped reviews, return complaint 
score 
tracker_detector.py Load Exodus CSV, match platform, count trackers, return sub-score 
scoring_engine.py Combine all 5 sub-scores into weighted composite, assign grade 
cache_manager.py PostgreSQL read/write for score caching

Anticipated Judge Questions 
Question Answer 
Can platforms game the 
score? 
Policy analysis is only 20%. The other 80% comes from independent 
third-party data — breach databases, tracker datasets, user complaints 
— which platforms cannot control. 
Is the data real-time? Breach and tracker data updates when new sources are released. 
Policy analysis is triggered fresh on every new search. Cached scores 
show “Last Updated” timestamp. 
Why is DPDP compliance 
important? 
India’s DPDP Act 2023 is newly enacted. TrustLens is one of the only 
tools that scores platforms specifically against this law, making it 
uniquely relevant for the Indian market. 
How is this different from 
existing tools? 
Most privacy tools tell you WHAT data is collected. TrustLens tells you 
HOW responsibly the platform behaves with it — across 5 independent 
automated signals, not self-reporting. 
Can this scale beyond a 
hackathon? 
Yes. The scoring engine is modular — new signals can be added. The 
Chrome extension creates a B2C distribution channel. At scale, 
platforms face market pressure to improve scores.
